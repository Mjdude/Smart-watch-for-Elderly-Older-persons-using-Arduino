### **Smart Watch for Elderly Persons using Arduino**  

This project is a **wearable smart watch** designed to assist elderly individuals by providing essential health monitoring and safety features. Built using **Arduino**, it helps in tracking vital parameters and ensuring the well-being of older adults.  

### **Key Features:**  
✅ **Health Monitoring** – Tracks heart rate, temperature, and movement patterns.  
✅ **Emergency Alerts** – Sends alerts in case of falls or unusual activity detection.  
✅ **User-Friendly Interface** – Simple and easy to use for elderly individuals.  
✅ **Compact & Wearable** – Designed for comfort and long-term use.  

📌 **Tech Used:** Arduino, Sensors (Heart Rate, Temperature, Accelerometer), C++, IoT Integration
